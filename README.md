# 잉크 슈터

브라우저에서 바로 하는 세로 스크롤 슈팅 게임입니다. 파랑·형광분홍 두 가지 리소 잉크로 찍은 인쇄물처럼 보이도록 만들었습니다.
설치나 빌드 없이 `index.html` 파일 하나로 동작합니다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 시작됩니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `←` `↑` `↓` `→` 또는 `W` `A` `S` `D` | 이동 |
| `Space` 누르고 있기 | 발사 |
| `P` 또는 `Esc` | 일시정지 |
| 화면을 누른 채 드래그 (터치·마우스) | 이동, 누르는 동안 자동 발사 |

## 규칙

| 적 | 움직임 | 점수 |
| --- | --- | --- |
| 방울 | 곧장 떨어짐 | 100 |
| 번짐 | 좌우로 흔들리며 내려옴 | 150 |
| 도장 | 4발을 맞아야 터지고, 플레이어를 조준해 쏨 (레벨 2부터) | 400 |

- 목숨은 3개입니다. 적과 부딪히거나 적 총알에 맞으면 하나 줄고, 2초간 무적이 됩니다.
- 1,500점마다 레벨이 오르고 적이 더 자주 나옵니다. 레벨 4부터 사선 탄이 추가됩니다.
- 최고 점수는 브라우저에 저장됩니다.

## 코드 구조

`index.html` 안의 스크립트는 아래 순서로 나뉘어 있고, 각 구역에 한국어 주석이 달려 있습니다.

1. **기본 설정**: 게임 좌표는 420×640 기준이며, 화면 크기에 맞게 CSS가 늘리고 줄입니다.
2. **게임 상태**: 플레이어, 총알, 적, 파편, 점수를 객체 하나에 담습니다.
3. **입력**: 키보드와 터치/마우스 입력을 기록합니다.
4. **화면 전환**: 시작, 일시정지, 게임 오버 화면을 전환합니다.
5. **게임 규칙**: 이동, 적 생성, 충돌 판정(원과 원 사이의 거리), 점수와 레벨을 처리합니다.
6. **그리기**: 상태를 읽어 캔버스에 그립니다. `multiply` 합성으로 잉크가 겹치는 효과를 냅니다.
7. **게임 루프**: `requestAnimationFrame`으로 1초에 약 60번 업데이트와 그리기를 반복합니다.
